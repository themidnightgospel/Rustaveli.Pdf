# Benchmark history

This branch holds data only: the benchmark numbers of every merge to `main`, which
[github-action-benchmark](https://github.com/benchmark-action/github-action-benchmark) adds to `benchmarks/data.js`
from the pre-merge workflow. The documentation site serves its charts at
https://themidnightgospel.github.io/Rustaveli.Pdf/benchmarks/, and each pull request is compared with the last
numbers here. Nothing on this branch is built or released.
