# Guides

How to write documents with Rustaveli.Pdf, task by task. Every example here is compiled by the test suite, and all
but the one that waits for Ctrl+C are run and their output checked, so what you copy works.

| Guide | Covers |
|---|---|
| [Getting started](getting-started.md) | Packages, a first document, frames, snippets, exporting |
| [Layout](layout.md) | Stacks, columns, tables, lists, layers, grids; modifiers; flow across pages |
| [Text](text.md) | Paragraphs, runs and type styles, page numbers, typefaces, OpenType features, style sheets |
| [Images and artwork](images-and-artwork.md) | Photographs, SVG, drawn artwork, images made for their box |
| [Output](output.md) | Export options, page images, SVG and XPS, PDF/A, tagged PDF and PDF/UA, protection |
| [Existing files](existing-files.md) | Merging, stamping, attaching, protecting and linearising PDF files |
| [Preview and debugging](preview-and-debugging.md) | The live preview and its inspector; seeing and naming frames; reading a layout failure |
| [Coming from QuestPDF](coming-from-questpdf.md) | The same ideas under their print names, side by side |

The [glossary](../GLOSSARY.md) lists every public name and what it means; the [parity checklist](../parity/PARITY.md)
maps QuestPDF's features to ours.
